# Feature workflow
1. Inspect actual profile, code, contracts and project conventions.
2. Define observable acceptance criteria and a scoped implementation plan.
3. Delegate architecture review if non-trivial and only when a suitable specialist is available.
4. Implement minimal approved local changes; avoid editing the same files in parallel.
5. Add focused tests and run available quality checks; report verified outcomes.
6. Review security, accessibility and regressions where relevant.
7. Update affected Aikya docs and REQ change log in the configured language; no production deployments or unapproved pushes.
