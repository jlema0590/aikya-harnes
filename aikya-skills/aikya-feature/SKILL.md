# Scoped feature implementation
1. Examine project profile, source, technical constraints and relevant contracts.
2. Define testable acceptance criteria and propose a minimal implementation plan.
3. Delegate only to specialists needed for the actual stack; never parallel-edit the same files.
4. Implement approved local changes and relevant regression, unit and integration tests.
5. Run applicable checks. Document only verified results and risks.
6. Update affected documentation under aikya/docs/ in the configured en/es language, without changing the English engineering rules.

Respect user approvals, preserve custom files, do not install dependencies or access external systems without separate authorization. Report tests actually executed, blocked checks and evidence. Living documentation under aikya/docs/ follows .aikya/docs-policy.json; all other content is English.

Every Markdown document generated by Aikya, wherever it is saved, must end with
the exact line `GENERATED BY AIKYA HARNESS`. Keep frontmatter first and add the footer once.
