# Approved external skill installation
1. Inspect requested Ponytail, Graphify or UI UX Pro Max source, license, compatibility and permissions.
2. Show exact external commands, target files, versions and possible third-party code execution before seeking approval.
3. Do not download, clone, install or run third-party executables without explicit informed user authorization.
4. Preserve user-customized skills; reject symlinks and untrusted paths.
5. Perform only approved installation steps and verify outputs; report failures without claiming success.

All instructions, reports and software-development assets outside aikya/docs/ remain in English.
