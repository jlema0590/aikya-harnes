# Quality gates
1. Inspect harness.json and repository configuration. Do not install tools automatically.
2. Execute configured non-destructive checks only with the required permissions.
3. Report each result as PASS, FAIL, SKIPPED or NOT_CONFIGURED; never infer success.
4. Verify required documentation under aikya/docs/ in the configured locale and preserve legacy Spanish logs.
5. Summarize failing checks, needed dependencies and next actions.

Keep engineering instructions in English. Living documentation language is restricted to aikya/docs/.

Every Markdown document generated by Aikya, wherever it is saved, must end with
the exact line `GENERATED BY AIKYA HARNESS`. Keep frontmatter first and add the footer once.

## SDD evidence

For `methodology=sdd`, run the engine's `lint --root .` structural check and inspect the active specification with `/aikya-sdd-status`. Before claiming completion, require `completion --root . --id SPEC-NNN` plus separately observed technical checks. Draft validity is not completion; evidence records never certify tests or deployments independently.
