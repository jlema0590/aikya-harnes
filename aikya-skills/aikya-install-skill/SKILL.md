# External skill installation alias

Follow /aikya-skills-install in the active project. Review source, version, license,
permissions and exact operations; obtain explicit approval before downloads or execution.
Invoke the approved external installer with --record-comparison to record actual
attempts in aikya/docs/tools/skill-comparison.md and update indice.md. Plan, status
and onboarding do not create this comparison. Never invent successful installation.
