# Project bootstrap planning
1. Inspect the project profile and approved technical decisions.
2. Establish module boundaries, required contracts, dependencies and project layout.
3. For new projects, recommend /aikya-init and /aikya-scaffold plan.
4. For existing repositories, recommend /aikya-analyze and incremental development rather than reinitializing code.
5. List concrete files, acceptance criteria, checks and risks before obtaining approval.
6. Record architecture/roadmap decisions under aikya/docs/ only when requested and in the chosen locale.

Never claim an external action or test was performed unless verified.
