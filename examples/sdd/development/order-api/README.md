# Ejemplo SDD — API de pedidos Java

`project_type=development`; activa `methodology=sdd` en /aikya-init o usa /aikya-answers con un perfil revisado.

Este escenario **no ejecuta herramientas**. Orden: especificar con spec.json, aclarar con clarify.json, aprobar spec, crear plan.json, aprobar plan, definir tasks.json y aprobar tasks. El agente implementa la tarea con permiso y aporta evidencias reales; el motor sólo registra estados.

Archivos JSON son ejemplos orientativos: las decisiones de negocio/autenticación requieren validación humana. No se incluyen pruebas ejecutadas ni resultados inventados.
